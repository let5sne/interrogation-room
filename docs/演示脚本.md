# 演示视频脚本（60–90 秒）

> 目标：让评审在 1 分钟内看懂「AI 是游戏机制本身，不是贴皮」。

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0–6s | 案情简报弹窗（雨夜书房 + 6 条证据） | 「古董商陈默死于书房。唯一的嫌疑人，是报案的合伙人林晚。」 |
| 6–14s | 关闭简报，输入「你最后一次见陈默是什么时候？」 | 「她不是普通的 NPC——她记得你说过的每句话。」 |
| 14–22s | 嫌疑人流式回复（打字机效果） | 「她会狡辩、会回避。」 |
| 22–34s | 点击「小区门口监控」→ 红色「矛盾！」+ 镇定条从 100 掉到 70 | 「出示监控，戳穿她的不在场证明——镇定暴跌。」 |
| 34–44s | 再点「擦拭过的奖杯」→ 又一个「矛盾！」，镇定掉到 40 | 「证据链在收紧，她开始慌了。」 |
| 44–54s | 点「施压」→ 嫌疑人反应，镇定继续掉 | 「无证据乱压会让她请律师——博弈是双向的。」 |
| 54–68s | 点「指认」→ 填「林晚 / 奖杯重击 / 挪用资金灭口」→ 破案结算 + 真相揭晓 | 「指认成立。真相：她挪用公款被陈默发现，杀人灭口。」 |
| 68–80s | 结尾定版：Logo + slogan | 「AI 不只是生成素材——它就是游戏机制本身。」 |

**录制要点**：
- 用真实 API Key 录，保证 AI 回复自然（可先对同一句问话跑几次挑最戏剧化的一条）。
- 突出「镇定条变化」和「矛盾！红字」，这是机制可视化最强的部分。
- 结尾一句话点题：「会记忆、会即兴、会因你而变的对手」。

**封面建议**：审讯室暗色调 + 林晚立绘 + 「她记得你说过的每句话」文案。
